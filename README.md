# My AI Novel

My AI Novel 是一个本地运行的 AI 小说生产流水线桌面程序。

当前测试版本放在：

```text
versions/v0.1.0-alpha/
```

运行方式：

```powershell
cd versions/v0.1.0-alpha
python run.py
```

测试方式：

```powershell
cd versions/v0.1.0-alpha
python -B -m unittest discover -s tests
```

本仓库不上传本地 API Key、用户小说项目、SQLite 运行数据、备份包和测试输出。
