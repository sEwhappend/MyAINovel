# v0.1.1-pyside6-preview

## 版本定位
这是在 `v0.1.0-alpha` 基础上的 UI 迁移预览版，目标是引入 PySide6 桌面 UI，同时保持旧版 tkinter UI 作为回退路径，确保程序可持续运行。

## 主要更新
- 新增 `src/my_ai_novel/pyside_ui.py`：
  - PySide6 版项目、总框架、资料库、章节、写作、设置、日志页面。
  - 复用现有业务层（`pipeline` / `storage` / `llm`），不改核心流水线接口。
- 新增 `src/my_ai_novel/ui_logic.py`：
  - 抽离 UI 纯逻辑与格式化函数，降低后续 UI 迁移耦合。
- 启动入口调整：
  - `app.py` 采用“PySide6 优先，legacy tkinter 自动回退”。
  - 启动日志可见当前实际命中的 UI 路径。
- 新增依赖：
  - `requirements.txt` 增加 `PySide6>=6.8,<7`。

## 兼容与回退
- 若本机未安装或无法加载 PySide6，程序自动回退到旧 UI。
- 旧 UI 代码仍保留在 `src/my_ai_novel/ui.py`，确保稳定性。

## 验证结果
- `python -B -m unittest tests.test_ui_smoke -v` 通过。
- `python -B -m unittest discover -s tests` 通过（173 tests）。

## 运行方式
```powershell
python run.py
```

## 已知限制
- 当前版本为迁移预览版，PySide6 与旧 UI 仍存在部分交互细节差异，后续继续对齐。
