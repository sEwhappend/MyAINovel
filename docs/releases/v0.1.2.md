# v0.1.2

## 版本定位
v0.1.2 是在 `v0.1.1-pyside6-preview` 基础上的稳定性小版本，重点修复设置界面在扫描模型/测试连接时的参数解析崩溃问题，并提供一份最小可运行发布包。

## 主要修复
- 修复 `Top-K` 为 `None/null/空值` 时触发 `int("None")` 报错的问题。
- 统一 LLM 参数空值处理逻辑：
  - `timeout_seconds`
  - `max_tokens`
  - `temperature`
  - `top_p`
  - `presence_penalty`
  - `frequency_penalty`
  - `top_k`
- 新增回归测试，覆盖 `top_k="None"` 场景。

## 发布包内容（最小可运行）
- `run.py`
- `requirements.txt`
- `README.md`
- `LICENSE`
- `src/`
- `docs/releases/v0.1.2.md`

## 未包含内容
- `.json/`（本地密钥）

```powershell
python -m pip install -r requirements.txt
python run.py
```
