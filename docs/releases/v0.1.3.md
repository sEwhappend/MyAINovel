# v0.1.3

## 版本定位
v0.1.3 是 PySide6 UI 预览版上的界面优化备份版本，重点保存当前可正常运行的桌面程序状态。

## 主要变化
- 项目页切换为更接近书架/书籍卡片的项目列表显示。
- 优化项目列表卡片的悬停、选中和按下反馈。
- 支持项目列表按可用宽度自适应多列显示。
- 优化项目详情页表单样式，去掉标签文字后的异常背景。
- 统一“总世界书 / 风格说明 / 总体概括”等多行输入框与普通输入框的视觉样式。
- 保留用户手动调整后的项目页左右栏比例与书架尺寸参数。

## 发布包内容
- `run.py`
- `requirements.txt`
- `README.md`

- `.json/`：本地 API Key 与模型配置
- `projects/`：用户项目数据
- `data/`：缓存或索引

- `agent-work/`
- `.git/`
- `.omx/`
- `test-output/`

## 运行方式
```powershell
python -m pip install -r requirements.txt
python run.py
```

## 验证
```powershell
python -B -m unittest tests.test_ui_smoke -v
```

本 release 包不包含 `tests/`，测试需在开发仓库中运行。
