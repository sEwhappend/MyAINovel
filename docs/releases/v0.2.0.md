# v0.2.0

## 版本定位
v0.2.0 是当前可上传到 GitHub Release 的 PySide6 桌面版备份包。这个版本保留了结构化小说生产流水线的主要功能，并把界面体验推进到以 PySide6 为主的本地桌面应用。

## 主要变化
- PySide6 UI 成为当前主界面，保留 `run.py` 直接启动方式。
- 主窗口和“标签化生成”窗口改为自定义无边框标题栏。
- 标题栏支持系统级拖动和缩放，使用 `startSystemMove()` / `startSystemResize()`，减少跨屏拖动时的异常放大风险。
- 启动时根据鼠标所在屏幕定位窗口，改善主屏/副屏缩放比例不一致时的启动位置问题。
- Windows 下使用 DWM 原生圆角，避免透明顶层窗口和 mask 带来的混合 DPI 崩溃风险。
- 最小化、窗口化/最大化、关闭按钮改为自绘 Windows 风格图形按钮，不再使用 Qt 默认标题栏图标。
- 项目页书架式项目列表继续保留，支持书籍卡片式项目展示。
- 标签化生成项目入口继续保留，可通过故事标签、写作标签和排除标签生成候选项目。
- 章节页和设置页增加竖向滚动容器，减少窗口高度变小时输入栏被压缩的问题。
- 章节页标题、时间、地点等单行输入框与设置页输入框统一最小高度。

## 发布包内容
- `run.py`
- `requirements.txt`
- `README.md`
- `LICENSE`
- `src/`
- `docs/releases/v0.2.0.md`

## 未包含内容
- `.json/`：本地 API Key、Base URL 和模型配置。
- `projects/`：用户小说项目数据。
- `data/`：SQLite 缓存、索引或运行时数据。
- `backups/`：历史备份与 release 压缩包。
- `agent-work/`：Agent 计划、报告和执行日志。
- `.git/` / `.omx/` / `.codex/`：本地开发和编排状态。
- `tests/` / `test-output/`：开发测试文件和测试输出。
- `__pycache__/` / `*.pyc`：Python 缓存文件。

## 运行方式
```powershell
python -m pip install -r requirements.txt
python run.py
```

## 验证
本次 release 包不包含 `tests/`，测试需在开发仓库中运行。

```powershell
python -B -m unittest tests.test_ui_smoke
python -B -m unittest discover -s tests
```

## 已知限制
- 真实窗口圆角效果依赖 Windows 桌面窗口管理器；自动化测试只能验证代码路径，不能直接验证肉眼效果。
- 混合 DPI 双屏环境差异较大，当前版本已避免按屏幕比例自动放大窗口，但仍建议在目标设备上手动确认启动位置和拖动体验。
- Release 包不包含本地配置和项目数据，其他电脑首次运行需要重新配置 LLM Provider、API Key 和模型。
