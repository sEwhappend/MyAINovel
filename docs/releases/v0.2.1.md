# v0.2.1

## 版本定位
v0.2.1 是当前可用于 GitHub Release 手动上传的 PySide6 桌面版备份包。本版本延续 v0.2.0 的本地桌面运行方式，并重点补充资料库中角色卡的标签化生成体验。

## 主要变化
- 资料库“角色卡”类型下，AI 自动创建资料可选择普通生成或标签化生成。
- 标签化生成角色卡采用独立弹窗，风格与“标签化生成新建空白项目”保持一致。
- 角色卡标签化弹窗使用无系统标题栏、自定义标题栏、搜索式需求输入和标签流布局。
- 角色标签支持三态交互：默认、选中、排除。
- 角色卡标签区不再区分“故事标签”和“写作标签”，改为单一连续标签流。
- `单主角` / `双主角` 从普通标签中移出，改为“主角结构”必选二选一。
- 标签化角色卡生成仍保持流式输出，生成结果保存为现有 `character` 资料条目。
- 不扩展资料库 kind；等级、技能、TS、恋爱关系等仍保存在角色卡 JSON 的模块或关系字段中。

## 发布包内容
- `run.py`
- `requirements.txt`
- `README.md`
- `LICENSE`
- `src/`
- `docs/releases/v0.2.1.md`

## 未包含内容
- `.json/`：本地 API Key、Base URL 和模型配置。
- `projects/`：用户小说项目数据。
- `data/`：SQLite 缓存、索引或运行时数据。
- `backups/`：历史备份与 release 压缩包。
- `agent-work/`：Agent 计划、报告和执行日志。
- `.git/` / `.omx/` / `.codex/`：本地开发和编排状态。
- `tests/` / `test-output/`：开发测试文件和测试输出。
- `__pycache__/` / `*.pyc`：Python 缓存文件。

## 运行方式
```powershell
python -m pip install -r requirements.txt
python run.py
```

## 验证
本次 release 包不包含 `tests/`，测试需在开发仓库中运行。

```powershell
python -B -m unittest tests.test_ui_smoke
python -B -m unittest tests.test_pipeline
python -B -m unittest discover -s tests
```

## 已知限制
- 真实 UI 视觉效果仍建议在目标 Windows 设备上手动确认。
- Release 包不包含本地配置和项目数据，其他电脑首次运行需要重新配置 LLM Provider、API Key 和模型。
- 标签化角色卡的互斥标签目前只处理 `单主角` / `双主角`；后续如有更多互斥标签组，需要继续迁移到结构化控件。
