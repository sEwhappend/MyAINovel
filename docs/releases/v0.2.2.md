# v0.2.2

## 版本定位
v0.2.2 是当前可用于 GitHub Release 手动上传的 PySide6 桌面版备份包。本版本延续 v0.2.1 的本地运行方式，重点补齐项目页标签辅助修改和新建项目标签分类一致性。

## 主要变化
- 项目页入口从“选择标签与引号”升级为“选择标签/辅助修改”。
- 新增项目标签/辅助修改弹窗，视觉与“标签化生成”弹窗保持一致。
- 项目辅助修改支持流式输出，生成过程中可直接看到模型返回内容。
- AI 修改当前项目时只生成 `project_patch` 建议，不自动保存项目；用户需要先应用到表单，再手动点击“保存项目”。
- 项目辅助修改限定可改字段：标题、题材、写作风格、目标读者、叙事视角、总世界书、风格说明、总体概括。
- “新建空白项目”的“标签化生成”弹窗标签分组改为：题材标签、设定标签、角色标签、结构标签、风格标签、排除/禁止标签。
- 新建项目标签化生成仍保留搜索过滤、三态标签、排除项和候选方案流式输出。

## 发布包内容
- `run.py`
- `requirements.txt`
- `README.md`
- `LICENSE`
- `src/`
- `docs/releases/v0.2.2.md`

## 未包含内容
- `.json/`：本地 API Key、Base URL 和模型配置。
- `projects/`：用户小说项目数据。
- `data/`：SQLite 缓存、索引或运行时数据。
- `backups/`：历史备份与 release 压缩包。
- `agent-work/`：Agent 计划、报告和执行日志。
- `.git/` / `.omx/` / `.codex/`：本地开发和编排状态。
- `tests/` / `test-output/`：开发测试文件和测试输出。
- `__pycache__/` / `*.pyc`：Python 缓存文件。

## 运行方式
```powershell
python -m pip install -r requirements.txt
python run.py
```

## 验证
本次 release 包不包含 `tests/`，测试需要在开发仓库中运行。

```powershell
python -B -m unittest tests.test_ui_smoke
python -B -m unittest tests.test_pipeline
python -B -m unittest discover -s tests
```

本次打包前验证结果：
- `tests.test_ui_smoke`：95 tests OK。
- `tests.test_pipeline`：40 tests OK。
- 全量测试：220 tests OK。

## 已知限制
- Release 包不包含本地配置和项目数据，其他电脑首次运行需要重新配置 LLM Provider、API Key 和模型。
- 项目辅助修改依赖模型返回可解析 JSON；如果提供商中断流式响应，仍可能需要重试。
- 当前“选择标签/辅助修改”只应用非空字段建议；更细的字段级 diff 预览可在后续版本补充。
