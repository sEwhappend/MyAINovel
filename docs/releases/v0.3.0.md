# v0.3.0

## 版本定位
v0.3.0 是当前可用于 GitHub Release 手动上传的 PySide6 桌面版备份包。本版本延续 v0.2.2 的本地运行方式，重点增强资料库关系图、Word 导出和写作版本操作，让小说项目从“生成内容”进一步走向“管理内容与检查关系”。

## 主要变化
- 新增人物关系图和事件关系图，用资料库中的角色卡、组织/势力、事件、地点、伏笔、规则等信息生成可视化关系。
- 人物关系图支持角色与组织/势力区分显示，缺失引用和推断节点会有不同提示。
- 事件关系图支持按事件时间顺序展示，并连接人物、地点、组织、伏笔、规则和禁止事项。
- 关系图默认显示全部关系、全部节点和弱推断关系，避免关系被默认过滤后看似丢失。
- 关系图新增关系范围和节点范围筛选，可在图谱过密时切换到核心关系、事件因果、出场/地点、伏笔/规则等视图。
- 优化关系图布局：人物图改为角色/组织分层布局，事件图改为时间轴布局，并缓解多个辅助节点重叠。
- “导出全书 Word”改为分节导出：程序会创建导出文件夹，并为每个已定稿小节生成一个独立 `.docx`。
- 写作界面支持删除选中的版本，并改善左右版本栏的标题和选中版本显示。
- 自动化写作的正文阶段支持流式输出，写作界面底部可显示当前生成内容。
- 章末资料库反写不再继承正文自动化的无限重试，避免最后一章完成后仍卡在 API 重试。
- 章节拆分和资料库生成继续保留角色说话风格结构，便于后续改善角色声音区分。

## 未包含内容
- `.json/`：本地 API Key、Base URL 和模型配置。
- `projects/`：用户小说项目数据。
- `data/`：SQLite 缓存、索引或运行时数据。
- `backups/`：历史备份与 release 压缩包。
- `agent-work/`：Agent 计划、报告和执行日志。
- `.git/` / `.omx/` / `.codex/`：本地开发和编排状态。
- `tests/` / `test-output/`：开发测试文件和测试输出。
- `__pycache__/` / `*.pyc`：Python 缓存文件。

## 运行方式
```powershell
python -m pip install -r requirements.txt
python run.py
```

## 已知限制
- Release 包不包含本地配置和项目数据，其他电脑首次运行需要重新配置 LLM Provider、API Key 和模型。
- 关系图目前仍使用直线连边；当节点和关系极多时，可能仍需要通过筛选、缩放和拖拽查看。
- 事件关系图依赖资料库事件中的 `phase`、`sequence`、`time_text`、`causes`、`participants` 等结构化字段；如果资料缺少这些字段，图谱顺序和连线会受影响。
- 分节 Word 导出只导出已定稿且存在定稿版本的小节，未定稿小节会跳过。
