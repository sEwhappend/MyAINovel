# v0.3.1

## 版本定位
v0.3.1 是可用于 GitHub Release 手动上传的 PySide6 桌面版备份包。本版本在 v0.3.0 的基础上，集中重做了资料库**关系图的绘制与交互**，并修复了一处会导致程序启动崩溃的缓存重建健壮性问题。目标是让关系图“一眼能看懂关系、节点不再叠在一起、可以自由摆布”。

## 主要变化
### 关系图绘制
- 连线由直线改为**曲线并贴合节点边界**，不再从圆心穿过节点。
- 同一对节点之间的**多条关系自动分车道扇形展开**，不再叠成一条线。
- 有向关系（隶属、领导、因果、师徒等）在目标端绘制**箭头**，方向一目了然。
- 关系类型按族**分色**，并在连线上显示**中文关系标签**。

### 中文化与防重叠
- 关系类型标签**全面中文化**：英文/变体关系词（friend、enemy、mentor、related 等）统一翻译，未识别的类型也兜底为中文「关联」，不再在图上出现英文。
- 节点名称**单行省略**显示（完整名见悬浮提示），长名不再换行溢出、压住相邻节点或连线。
- 弱推断关系与「同场」关系**默认不显示文字标签**，并对会压在节点上的标签自动避让，密集图更清爽。

### 交互
- **节点可自由拖动，连线、箭头、标签实时跟随**；在节点或其标签上按下即可拖动，空白处按下仍可平移画布。
- 新增**图例**：说明颜色对应的关系、节点形状、箭头与虚线含义。
- 手动缩放/平移后**刷新图谱不再跳回初始视图**；「适配窗口」可恢复自动适配。
- 新增**「聚焦选中」**：只展开选中节点的相邻关系，便于在大图中聚焦局部。

### 稳定性
- 修复：当本地项目文件夹中存在共用同一全局 id 的资料条目（多见于直接复制项目文件夹）时，重建缓存会因唯一约束冲突而崩溃。现已改为对冲突副本重新分配 id，两个条目都保留，程序不再启动失败。

- `.json/`：本地 API Key、Base URL 和模型配置。
- `projects/`：用户小说项目数据。
- `styles/`：用户文风库数据。
- `data/`：SQLite 缓存、索引或运行时数据。
- `风格化参考文本/`：本地参考文本（含版权样本），不随包分发。
- `backups/`：历史备份与 release 压缩包。
- `agent-work/`：Agent 计划、报告和执行日志。
- `.git/` / `.omx/` / `.codex/` / `.claude/`：本地开发和编排状态。
- `tests/` / `test-output/`：开发测试文件和测试输出。
- `__pycache__/` / `*.pyc`：Python 缓存文件。

## 运行方式
```powershell
python -m pip install -r requirements.txt
python run.py
```
首次运行需要在设置界面配置 LLM Provider、API Key、Base URL 和模型。

## 验证
本次 release 包不包含 `tests/`，测试需要在开发仓库中运行。

```powershell
python -B -m unittest tests.test_relation_graph tests.test_ui_smoke
python -B -m unittest discover -s tests
```

- 全量测试：383 tests OK。

## 已知限制
- Release 包不包含本地配置和项目数据，其他电脑首次运行需要重新配置 LLM Provider、API Key 和模型。
- 关系图中手动拖动摆放的位置在「刷新图谱」后会重置回自动布局（拖动位置暂不持久化）。
- 事件关系图依赖资料库事件中的 `phase`、`sequence`、`time_text`、`causes`、`participants` 等结构化字段；如果资料缺少这些字段，图谱顺序和连线会受影响。
- 分节 Word 导出只导出已定稿且存在定稿版本的小节，未定稿小节会跳过。
